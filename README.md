# 🎬 Netflix Clone

A responsive front-end clone of the Netflix landing page built to practice modern web development concepts and responsive UI design. The project recreates the look and feel of Netflix's homepage while focusing on clean layouts, user experience, and responsiveness.

## 🌐 Website Chosen

**Netflix Landing Page**

The project is inspired by Netflix's official homepage and replicates its modern design, including the hero section, content sections, FAQs, and footer while maintaining a responsive layout across different screen sizes.

**Live Demo:** [View Live Project](https://clone-netflix-chi-three.vercel.app)

---

## 🛠️ Tech Stack Used

- **HTML5** – Structure of the website
- **CSS3** – Styling, animations, Flexbox, Grid, and responsive design
- **JavaScript (Vanilla JS)** – Interactive components such as the FAQ accordion
- **Vercel** – Deployment and hosting

---

## ✨ Features Implemented

- 🎥 Netflix-inspired responsive landing page
- 📱 Mobile, tablet, and desktop responsive design
- 🎨 Modern UI closely matching Netflix's branding
- 📺 Hero section with call-to-action
- 🔥 Trending/featured content sections
- 💻 Multiple feature showcase sections
- ❓ Interactive FAQ accordion
- 🌍 Language selection dropdown
- 📧 Email input and "Get Started" call-to-action
- 🦶 Fully designed footer with useful links
- ⚡ Fast loading static website

---

## ⚠️ Known Limitations

- This is a **front-end clone only**; no backend functionality is implemented.
- User authentication and account management are not available.
- Movies and TV shows cannot be streamed.
- Search functionality is not implemented.
- Content displayed is static and not fetched from an API.
- The project is intended solely for educational and learning purposes and is **not affiliated with Netflix**.
